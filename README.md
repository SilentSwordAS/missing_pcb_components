# missing_pcb_components
Python based standalone application for identifying missing parts on a PCB.

## Instructions:
- Run `pip -r requirements.txt` to install the necessary dependencies.
- Run `streamlit run app.py` to launch the application.
- Ensure that the file yolo26m.pt is present in the directory.
- Upload the image of the good board, draw and label the bounding boxes.
- Start the training and after it is done, move to the next tab for testing.
